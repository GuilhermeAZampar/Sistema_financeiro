 Sistema Financeiro

Desenvolvi esta aplicação para organizar receitas e despesas e acompanhar o saldo pessoal em um só lugar.

Implementei a API com Flask, a interface com React e TypeScript e a integração com PostgreSQL. O sistema permite cadastrar, editar e excluir transações, filtrar por categoria e consultar um painel financeiro com layout responsivo.

Para executar localmente, configure as variáveis de ambiente e rode:

podman compose -f docker-compose.yaml up -d --build
